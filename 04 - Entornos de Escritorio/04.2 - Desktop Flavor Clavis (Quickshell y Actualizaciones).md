# 🐚 Desktop Flavor Clavis: Quickshell, Entorno Niri y Actualizador

> [!NOTE]
> **Navegación:**
> * Anterior: [[04.1 - Niri Core (niri-edge y key-cli)|04.1 - Niri Core (niri-edge y key-cli)]]
> * Siguiente: [[04.3 - Apariencia Clavis (MacTahoe y Fcitx5)|04.3 - Apariencia Clavis (MacTahoe y Fcitx5)]]
> * Volver a: [[04.0 - Entornos de Escritorio (MOC)|📑 Índice de Capa]]

Este módulo documenta el despliegue del entorno de escritorio **Clavis Shell**, construido sobre la suite de widgets e interfaces de **Quickshell** (Qt 6 / C++ nativo) con diseño visual Liquid Glass inspirado en macOS, su integración con `niri-edge` y el sistema de mantenimiento automatizado mediante `systemd`.

---

## 🎯 Decisiones de Arquitectura

1. **Compilación a Nivel de Sistema:**
   Clavis Shell compila plugins nativos en C++ para Qt Quick (`Clavis.Weather`, `Clavis.Cava`, `Clavis.Niri`, `Clavis.WindowPreview`, etc.) que residen en `/usr/lib/qt6/qml/Clavis` y distribuye su configuración base en `/etc/xdg/quickshell/clavis`. Se instalan a nivel de sistema (`sudo cmake --install`).
2. **Aislamiento Estricto por Usuario:**
   Toda la configuración específica del usuario (`~/.config/niri/config.kdl`, fragmentos KDL, temas Matugen locales, servicios systemd) se ejecuta estrictamente bajo la identidad del usuario objetivo (`niri` / `sura`).
3. **Compilación desde `personal` (`HEAD`):**
   Las versiones estáticas carecen de parches críticos (refresco del modelo de calendario, eventos de desbloqueo en Quickshell y estabilidad en sliders).
4. **Dependencias Críticas de AUR:**
   - **`libcava`:** Biblioteca compartida `libcava.so` requerida para el ecualizador de audio en tiempo real vía PipeWire.
   - **`qt6-m3shapes-git`:** Provee tipos QML para renderizado de curvas y morfologías dinámicas Material 3.
   - **`ttf-lxgw-wenkai-screen`:** Tipografía de interfaz recomendada para pantallas de alta densidad.

### 2. Compilación de Clavis Shell desde Fork Propio

```bash
BUILD_DIR="${BUILD_DIR:-/opt/src}"
cd "$BUILD_DIR"

if [ ! -d "quickshell" ]; then
    git clone -b personal https://github.com/robert-flo/quickshell.git quickshell
    git -C quickshell remote add upstream https://github.com/StatIndet/quickshell.git
    git -C quickshell remote set-url --push upstream DISABLE
    cd quickshell
else
    cd quickshell
    git switch personal
    git pull --ff-only
fi

# 1. Empaquetar y verificar recursos meteorológicos
/usr/bin/python3 scripts/release.py bundle-resources --cache /tmp/clavis-cache
/usr/bin/python3 scripts/release.py verify-resources

# 2. Configurar build con CMake y Ninja
cmake -S . -B build -G Ninja \
    -DCMAKE_BUILD_TYPE=Release \
    -DBUILD_TESTING=ON \
    -DCMAKE_INSTALL_PREFIX=/usr \
    -DCMAKE_INSTALL_LIBDIR=lib \
    -DCLAVIS_CONFIG_INSTALL_DIR=/etc/xdg/quickshell/clavis \
    -DPython3_EXECUTABLE=/usr/bin/python3

# 3. Compilar todos los módulos nativos
cmake --build build

# 4. Validar suite de pruebas (27 contratos)
ctest --test-dir build --output-on-failure

# 5. Instalar en el sistema
sudo cmake --install build
```

### 3. Configuración del Entorno de Usuario (`niri` / `sura`)

> [!IMPORTANT]
> En usuarios configurados con dotbare (`niri` y `sura`), los archivos de configuración provienen del repositorio [robert-flo/niri-dotfiles](https://github.com/robert-flo/niri-dotfiles) (ver [[06.1 - Gestion de Dotfiles con dotbare|06.1 - Gestión de Dotfiles]]). Para un usuario nuevo sin dotfiles:

```bash
TARGET_USER="${1:-niri}"
TARGET_HOME="$(getent passwd "$TARGET_USER" | cut -d: -f6)"
TARGET_UID="$(id -u "$TARGET_USER")"

echo "==> Configurando entorno para: $TARGET_USER"

# 1. Copiar base de configuración niri
sudo mkdir -p "$TARGET_HOME/.config/niri/clavis"
sudo cp /usr/share/doc/niri/default-config.kdl "$TARGET_HOME/.config/niri/config.kdl"
sudo chown -R "$TARGET_USER:$TARGET_USER" "$TARGET_HOME/.config/niri"

# 2. Generar fragmentos modulares de Clavis Shell
for feature in binds layer-rules effects cursor minimize-animation hot-corners; do
    sudo -u "$TARGET_USER" -H python3 /etc/xdg/quickshell/clavis/scripts/system/niri_config.py \
        "{\"operation\": \"setup\", \"feature\": \"$feature\"}"
done

# 3. Validar sintaxis
sudo -u "$TARGET_USER" -H niri validate -c "$TARGET_HOME/.config/niri/config.kdl"

# 4. Habilitar servicios de sesión systemd
sudo -u "$TARGET_USER" -H XDG_RUNTIME_DIR="/run/user/$TARGET_UID" systemctl --user daemon-reload
sudo -u "$TARGET_USER" -H XDG_RUNTIME_DIR="/run/user/$TARGET_UID" systemctl --user enable \
    clavis-shell.service clavis-clipboard.service
```

## 🔄 Procedimiento y Automatización de Actualizaciones Diarias

El script centralizado actualiza las ramas `personal` de los forks y compila con la identidad del dueño de `/opt/src`. Copia idéntica preservada en `assets/system/usr/local/bin/update-niri-desktop.sh`.

### Script `/usr/local/bin/update-niri-desktop.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

SRC_DIR="${SRC_DIR:-/opt/src}"
BUILD_USER="${BUILD_USER:-$(stat -c %U "$SRC_DIR")}"
BUILD_HOME="$(getent passwd "$BUILD_USER" | cut -d: -f6)"

as_builder() {
    runuser -u "$BUILD_USER" -- env -i \
        HOME="$BUILD_HOME" USER="$BUILD_USER" LOGNAME="$BUILD_USER" \
        PATH=/usr/local/bin:/usr/bin:/bin \
        CARGO_NET_GIT_FETCH_WITH_CLI=true \
        bash -c "$1"
}

echo "================================================================"
echo "  Actualizando Niri Desktop desde forks (rama personal)         "
echo "================================================================"

# 1. niri-edge
if [ -d "$SRC_DIR/niri-edge" ]; then
    echo ">> [1/7] Actualizando niri-edge..."
    as_builder "cd '$SRC_DIR/niri-edge' && git fetch origin && { git merge --ff-only '@{u}' || true; } && cargo build --release"
    install -Dm755 "$SRC_DIR/niri-edge/target/release/niri" /usr/local/bin/niri
fi

# 2. key-cli
if [ -d "$SRC_DIR/key-cli" ]; then
    echo ">> [2/7] Actualizando key-cli..."
    as_builder "cd '$SRC_DIR/key-cli' && git fetch origin && { git merge --ff-only '@{u}' || true; } && /usr/bin/python3 scripts/installer.py"
    as_builder "cd '$SRC_DIR/key-cli' && /usr/bin/python3 scripts/installer.py --keyboard enable --acknowledge-keyboard-access --apply"
    setcap 'cap_dac_read_search=ep' /usr/local/libexec/key-cli/key-cpu-power
    [ -f "$SRC_DIR/key-cli/completions/key.fish" ] && install -Dm644 "$SRC_DIR/key-cli/completions/key.fish" /usr/share/fish/vendor_completions.d/key.fish
fi

# 3. quickshell (Clavis Shell)
if [ -d "$SRC_DIR/quickshell" ]; then
    echo ">> [3/7] Actualizando Clavis Shell..."
    as_builder "cd '$SRC_DIR/quickshell' && git fetch origin && { git merge --ff-only '@{u}' || true; } \
        && { /usr/bin/python3 scripts/release.py bundle-resources --cache /tmp/clavis-cache || true; } \
        && cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DCMAKE_INSTALL_PREFIX=/usr -DCMAKE_INSTALL_LIBDIR=lib -DCLAVIS_CONFIG_INSTALL_DIR=/etc/xdg/quickshell/clavis -DPython3_EXECUTABLE=/usr/bin/python3 \
        && cmake --build build"
    cmake --install "$SRC_DIR/quickshell/build"
fi

# 4. clavis-fish-theme
if [ -d "$SRC_DIR/clavis-fish-theme" ]; then
    echo ">> [4/7] Actualizando clavis-fish-theme..."
    as_builder "cd '$SRC_DIR/clavis-fish-theme' && git fetch origin && { git merge --ff-only '@{u}' || true; } && cargo build --release --locked"
    install -Dm755 "$SRC_DIR/clavis-fish-theme/target/release/clavis-fish-theme" /usr/local/bin/clavis-fish-theme
fi

# 5. my_zsh_prompt
if [ -d "$SRC_DIR/my_zsh_prompt" ]; then
    echo ">> [5/7] Actualizando my_zsh_prompt..."
    as_builder "cd '$SRC_DIR/my_zsh_prompt' && git fetch origin && { git merge --ff-only '@{u}' || true; } && make clean && make"
    install -Dm755 "$SRC_DIR/my_zsh_prompt/prompt_dev" /usr/local/bin/prompt
fi

# 6. SPlayer-Next
if [ -d "$SRC_DIR/SPlayer-Next" ]; then
    echo ">> [6/7] Actualizando SPlayer-Next..."
    as_builder "cd '$SRC_DIR/SPlayer-Next' && git fetch origin && { git merge --ff-only '@{u}' || true; } \
        && sed -i 's/locale: \"zh-CN\"/locale: \"en-US\"/' src/i18n/index.ts \
        && sed -i 's/ref<LocaleCode>(\"zh-CN\")/ref<LocaleCode>(\"en-US\")/' src/stores/settings.ts \
        && sed -i 's/defaultValue: \"zh-CN\"/defaultValue: \"en-US\"/' src/settings/categories/general.ts \
        && sed -i 's/currentLocale: LocaleCode = \"zh-CN\"/currentLocale: LocaleCode = \"en-US\"/' electron/main/utils/i18n.ts \
        && pnpm build:unpack"
    mkdir -p /opt/SPlayer-Next
    cp -a "$SRC_DIR/SPlayer-Next/dist/linux-unpacked/." /opt/SPlayer-Next/
    chmod 755 /opt/SPlayer-Next/chrome-sandbox
    ln -sf /opt/SPlayer-Next/SPlayer-Next /usr/local/bin/splayer-next
fi

# 7. Actualizar paquetes oficiales del sistema
echo ">> [7/7] Verificando paquetes del sistema..."
pacman -Syu --needed --noconfirm

echo "✅ Actualización completada exitosamente."
```

### Automatización mediante Timer de Systemd

```ini
# /etc/systemd/system/niri-update.service
[Unit]
Description=Actualización Diaria Niri Desktop y Clavis Shell
After=network-online.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/update-niri-desktop.sh
```

```ini
# /etc/systemd/system/niri-update.timer
[Unit]
Description=Timer para Actualización Diaria Niri Desktop

[Timer]
OnCalendar=*-*-* 04:00:00
Persistent=true

[Install]
WantedBy=timers.target
```

```bash
# Habilitar el timer en el sistema
sudo systemctl daemon-reload
sudo systemctl enable --now niri-update.timer
```

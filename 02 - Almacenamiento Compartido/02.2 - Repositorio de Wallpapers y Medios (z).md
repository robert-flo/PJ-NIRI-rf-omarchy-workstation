# 🌄 Repositorio de Wallpapers y Medios Compartidos (`/z`)

> [!NOTE]
> **Navegación de Capa:**
> * Anterior: [[02.1 - Directorio Compartido (z) y Permisos ACL]]
> * Subir al Hub: [[02.0 - Almacenamiento Compartido (MOC)|📑 Hub de Capa]]

Este módulo documenta las colecciones multimedia centralizadas en `/z/wallpaper-collection` y los fondos de pantalla del sistema, garantizando que tanto los fondos estáticos de **Clavis** como los fondos animados en video de **Nyxuri / mpvpaper** estén disponibles para todos los usuarios sin duplicar gigabytes de datos en sus respectivos `$HOME`.

## 🛠️ Procedimiento de Despliegue en `/z/wallpaper-collection`

Para clonar o actualizar la colección completa en el directorio compartido:

```bash
cd /z
if [ ! -d "/z/wallpaper-collection/.git" ]; then
    echo "==> Clonando colección centralizada de wallpapers..."
    git clone --depth 1 https://github.com/robert-flo/wallpaper-collection.git
else
    echo "==> Actualizando colección existente..."
    git -C /z/wallpaper-collection pull origin master
fi

# Asegurar permisos compartidos del grupo wheel
sudo chgrp -R wheel /z/wallpaper-collection
sudo chmod -R g+rwX /z/wallpaper-collection
```

## 🖼️ Enlace y Consumo desde los Usuarios

### 1. Para Nyxuri / Noctalia Shell (`nyxuri` y `nyxuri-test`)
El selector de wallpapers de Noctalia Shell busca imágenes y videos en `~/.config/noctalia/wallpapers` o rutas relativas. Se enlazan simbólicamente hacia `/z/wallpaper-collection`:

```bash
TARGETS=("nyxuri" "nyxuri-test")
for u in "${TARGETS[@]}"; do
    if id "$u" &>/dev/null; then
        sudo -u "$u" -H bash -c '
        mkdir -p "$HOME/.config/noctalia"
        ln -sfn /z/wallpaper-collection "$HOME/.config/noctalia/wallpapers"
        '
    fi
done
```

### 2. Para Clavis Shell (`niri`, `niri-classic`, `niri-test`)
Clavis escanea la carpeta declarada en `~/.config/clavis/config.json` (`folder: "/z/wallpaper-collection"`). 

Para garantizar compatibilidad y evitar duplicar medios en `$HOME`:
* **Única Fuente Canónica (SSoT):** `/z/wallpaper-collection` aloja tanto los fondos estáticos en la raíz como los fondos animados en bucle (`video/`).
* **Optimización Estricta de Video (Bajo Consumo GPU):** Todos los videos en `/z/wallpaper-collection/video/` están estrictamente optimizados a **1080p Full HD @ <=30 FPS, códec H.264 (VA-API) y sin pistas de audio**, evitando sobrecargar la GPU o activar sesiones de sonido innecesarias con `mpvpaper`.
* **Slots Rápidos Directos (Super + Shift + 1 .. 9):** Los números del **1 al 9** están reservados para los atajos rápidos de escritorio. Basta con nombrar cualquier archivo como `1.mp4`, `2.mp4` (en `video/` o en raíz) o `3.png`, `4.jpg` (en raíz) para asignarle el slot de forma inmediata y sin necesidad de enlaces simbólicos (`symlinks`) ni carpetas intermedias. Si existen dos archivos con el mismo número, el modificado más recientemente toma la prioridad activa.
* **Dotfiles Ligeros (Chezmoi SSoT):** El repositorio `/z/rf-dotfiles` únicamente versiona **3 wallpapers estáticos de referencia** (`statindet/wallhaven-rq6yqm.png`, `statindet/wallhaven-rq6yqm.jpg` y `wallhaven-5y3571.jpg`) para que cualquier clon limpio funcione de fábrica; en la estación de trabajo, Chezmoi despliega el enlace simbólico `~/.local/share/clavis/wallpapers/video -> /z/wallpaper-collection/video`.
* **Herramienta de Optimización:** `optimize-wallpaper` reside en `~/.local/bin/optimize-wallpaper` y detecta automáticamente `/z/wallpaper-collection/video` como destino preferido.

```bash
# Ejemplo: Optimizar un nuevo video y añadirlo a la colección compartida
optimize-wallpaper ~/Downloads/nuevo_fondo.mp4
# El video se procesa a 1080p@30fps sin audio y se deposita en /z/wallpaper-collection/video/
```

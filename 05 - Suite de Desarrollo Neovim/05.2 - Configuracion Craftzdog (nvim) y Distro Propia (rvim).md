## ⚡ 1. Distribución Principal por Defecto: `rvim` (`nvim`)

Ubicada en `/z/nvims/rvim`, es tu propia distribución personal minimalista mantenida en [`robert-flo/rvim`](https://github.com/robert-flo/rvim):

* **Rol en el sistema:** **Editor principal por defecto**. Se ejecuta al escribir `nvim`, al invocar `rvim` y como editor predeterminado de Git (`$EDITOR`).
* **Características Clave:**
  - Carga ultra-rápida optimizada para el flujo de trabajo diario de desarrollo y scripting.
  - **Soporte Bivalente de Temas (Claro / Oscuro):**
    - **Modo Claro (`clavis-light`):** Tema nativo ergonómico calibrado sobre fondo papel reposado `#eff1f5` con texto carbón `#3a3d52`, tonos joya de alto contraste y eliminación de deslumbramientos en diagnósticos y comentarios.
    - **Modo Oscuro (`solarized-osaka`):** Mantiene intacta la estética vivaz y profunda de Craftzdog (`solarized-osaka.nvim`) con transparencia adaptativa.
    - **Conmutación en caliente con `<leader>T`:** Permite alternar instantáneamente entre modo claro y oscuro sin reiniciar el editor.
    - **Autodetección:** Sincroniza su aspecto de arranque con la preferencia de modo (`light` / `dark`) configurada en `~/.config/clavis/config.json`.
  - Integración con Snacks UI (dashboard personalizado, picker nativo, explorador de buffers).
  - Resaltado contextual semántico con `nvim-treesitter`.
  - Iconografía ligera con `mini.icons` y barra de estado reactiva.
  - Soporte integrado para toolchain moderno (Rust, Python, Go, Bash, C++, Android).

## 🐶 2. Configuración IDE Completa Aislada: Craftzdog (`cvim` / `craftvim`)

Ubicada en `/z/nvims/dotfiles-craftzdog/dot_config/nvim`, representa un entorno IDE de desarrollo moderno y reactivo basado en las últimas capacidades nativas de Neovim 0.12:

* **Invocación:** Comandos `cvim` o `craftvim`.
* **Aislamiento:** Emplea `NVIM_APPNAME="cvim"`.
* **Puntos Clave de la Arquitectura:**
  - **Gestión Nativa con `vim.pack`**: No utiliza Lazy.nvim ni Packer. Emplea la API oficial incorporada en Neovim >= 0.12, controlando las versiones exactas mediante `nvim-pack-lock.json`.
  - **Tema Solarized Osaka**: Paleta cromática profunda `solarized-osaka.nvim` diseñada especialmente para terminales modernas con soporte de transparencia y contraste regulado.
  - **Suite Snacks.nvim**:
    - `snacks.picker`: Explorador de archivos, buffers y búsqueda en vivo (`live_grep` con ripgrep y `find_files` con fd).
    - `snacks.dashboard`: Pantalla de bienvenida interactiva.
    - `snacks.notifier`: Notificaciones de sistema flotantes no intrusivas.
  - **Árboles de Sintaxis con `nvim-treesitter`**: Compilado y optimizado.

## 🚀 3. Distribución Minimalista: nvim2k (`2kvim`)

Ubicada en `/z/nvims/nvim2k`, portada desde [`2KAbhishek/nvim2k`](https://github.com/2KAbhishek/nvim2k):

* **Invocación:** Comando `2kvim`.
* **Aislamiento:** Emplea `NVIM_APPNAME="2kvim"`.
* **Propósito:** Entorno complementario ligero enfocado en edición rápida de notas, markdown y utilidades con UI estética Onedark/Snacks.

## 📊 Matriz de Rutas y Aislamiento XDG

Gracias a la variable nativa `NVIM_APPNAME`, cada distribución cuenta con almacenamiento independiente sin riesgo de que plugins o parsers colisionen:

| Comando | Distribución | Configuración (`stdpath('config')`) | Plugins y Datos (`stdpath('data')`) | Caché (`stdpath('cache')`) |
|---|---|---|---|---|
| `nvim` | **rvim** | `~/.config/nvim` $\rightarrow$ `/z/nvims/rvim` | `~/.local/share/nvim` | `~/.cache/nvim` |
| `rvim` | **rvim** | `~/.config/rvim` $\rightarrow$ `/z/nvims/rvim` | `~/.local/share/rvim` | `~/.cache/rvim` |
| `cvim` / `craftvim` | **Craftzdog** | `~/.config/cvim` $\rightarrow$ `/z/nvims/dotfiles-craftzdog/...` | `~/.local/share/cvim` | `~/.cache/cvim` |
| `2kvim` | **nvim2k** | `~/.config/2kvim` $\rightarrow$ `/z/nvims/nvim2k` | `~/.local/share/2kvim` | `~/.cache/2kvim` |

## 🔄 Flujos de Trabajo y Mantenimiento

### 1. Desarrollar y Mejorar `rvim`
Al residir de forma centralizada en `/z/nvims/rvim`, cualquier cambio en `init.lua`, mapeos o módulos se refleja de inmediato para todos los usuarios:

```bash
cd /z/nvims/rvim
nvim .
git status
git commit -am "feat: agregar mejora a rvim"
git push origin main
```

### 2. Sincronización Automatizada con `forkhub`
En lugar de recordar comandos manuales de git para cada fork:
```bash
# Auditar toda la flota de Neovim
forkhub status

# Actualizar idempotentemente solo el grupo neovim
forkhub update --group neovim
```

El servicio `forkhub.timer` realiza este ciclo de forma transparente cada madrugada a las 04:30 AM.

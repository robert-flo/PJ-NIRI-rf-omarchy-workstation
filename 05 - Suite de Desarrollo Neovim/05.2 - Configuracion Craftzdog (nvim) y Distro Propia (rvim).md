## 🐶 1. Configuración Principal: Fork Craftzdog (`nvim`)

Ubicada en `/z/nvims/dotfiles-craftzdog/dot_config/nvim`, representa un entorno IDE de desarrollo moderno y reactivo basado en las últimas capacidades nativas de Neovim 0.12:

### Puntos Clave de la Arquitectura:
- **Gestión Nativa con `vim.pack`**: No utiliza Lazy.nvim ni Packer. Emplea la API oficial incorporada en Neovim >= 0.12, controlando las versiones exactas mediante `nvim-pack-lock.json`.
- **Tema Solarized Osaka**: Paleta cromática profunda `solarized-osaka.nvim` diseñada especialmente para terminales modernas con soporte de transparencia y contraste regulado.
- **Suite Snacks.nvim**:
  - `snacks.picker`: Explorador de archivos, buffers y búsqueda en vivo (`live_grep` con ripgrep y `find_files` con fd).
  - `snacks.dashboard`: Pantalla de bienvenida con accesos rápidos.
  - `snacks.notifier`: Notificaciones de sistema flotantes no intrusivas.
- **Árboles de Sintaxis con `nvim-treesitter`**: Resaltado semántico contextual compilado con gcc/clang.
- **Iconografía Unificada con `mini.icons`**: Glifos limpios para exploradores de archivos y barras de estado sin dependencias pesadas.

## ⚡ 2. Distribución Secundaria Aislada: `rvim`

Ubicada en `/z/nvims/rvim`, es tu propia distribución personal minimalista mantenida en [`robert-flo/rvim`](https://github.com/robert-flo/rvim):

### Aislamiento por `NVIM_APPNAME`:
Al invocarse mediante el ejecutable `/usr/local/bin/rvim`, Neovim reasigna automáticamente todas sus rutas XDG:

| Ruta Estándar (`nvim`) | Ruta Aislada (`rvim`) | Rol |
|---|---|---|
| `~/.config/nvim` | `~/.config/rvim` | Configuración (`init.lua`, `lua/`) |
| `~/.local/share/nvim` | `~/.local/share/rvim` | Plugins instalados, parsers y runtime |
| `~/.local/state/nvim` | `~/.local/state/rvim` | Historial de deshacer, marcas y shada |
| `~/.cache/nvim` | `~/.cache/rvim` | Caché de análisis LSP y bytecode |

## 🔄 Flujos de Trabajo y Mantenimiento

### 1. Desarrollar y Mejorar `rvim`
Al residir de forma centralizada en `/z/nvims/rvim`, cualquier cambio a `init.lua`, mapeos de teclas o módulos se refleja de inmediato para todos los usuarios de la máquina:

```bash
cd /z/nvims/rvim
# Modificar archivos con nvim o rvim
git status
git commit -am "feat: agregar nuevo plugin / configurar lsp"
git push origin main
```

### 2. Sincronizar Cambios de Craftzdog
Para traer actualizaciones o mejoras del fork de Craftzdog:

```bash
cd /z/nvims/dotfiles-craftzdog
git fetch origin
git pull --ff-only origin feat/late-2026
```

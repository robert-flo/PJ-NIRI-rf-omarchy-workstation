# 🗄️ Archivos de Sistema de Referencia (`assets/system`)

> [!NOTE]
> **Navegación:**
> * Anterior: [[07.3 - Guia de Video Showcase y Recursos Audiovisuales|07.3 - Guía de Video Showcase y Recursos Audiovisuales]]
> * Volver a: [[00.0 - Mapa General del Sistema (MOC)|Índice General (MOC)]]

El directorio [[assets/system/README|assets/system/]] preserva **copias exactas e idénticas** de todos los archivos fuera de `$HOME` que gestiona esta arquitectura, tomadas directamente de la máquina de referencia. La ruta dentro de `assets/system/` corresponde a la ruta absoluta de destino en el sistema operativo.

> [!IMPORTANT]
> Los archivos de usuario (`~/.config/`, dotfiles) **no** van aquí: viven en sus respectivos repositorios ([robert-flo/niri-dotfiles](https://github.com/robert-flo/niri-dotfiles) y [robert-flo/PJ-NIRI-fo-nyxuri](https://github.com/robert-flo/PJ-NIRI-fo-nyxuri)). Si modificas un archivo de sistema en la máquina, actualiza su copia aquí y la nota correspondiente.

## 🗄️ Directorios Compartidos del Sistema

| Directorio | Propietario / Permisos | Rol y Contenido |
|---|---|---|
| **`/z`** | `root:wheel` / `2775` (setgid + ACLs) | Raíz del almacenamiento colaborativo entre todos los perfiles de usuario. |
| **`/z/nvims`** | `omarchy:wheel` / `2775` (setgid) | Repositorios base compartidos de Neovim (`dotfiles-craftzdog` y `rvim`). |

## 🛠️ Procedimiento de Despliegue desde el Vault

```bash
VAULT="/home/omarchy/Work/tries/2026-10-23-robert-flo-PJ-NIRI-rf-omarchy-workstation"
A="$VAULT/assets/system"

# 1. sudoers: validar sintaxis antes de instalar
for u in omarchy gracie niri sura nyxuri nyxuri-test; do
    if [ -f "$A/etc/sudoers.d/04_$u" ]; then
        sudo visudo -cf "$A/etc/sudoers.d/04_$u" && \
          sudo install -m 0440 -o root -g root "$A/etc/sudoers.d/04_$u" "/etc/sudoers.d/04_$u"
    fi
done
sudo visudo -c

# 2. SDDM
sudo install -Dm644 "$A/etc/sddm.conf.d/10-theme.conf"         /etc/sddm.conf.d/10-theme.conf
sudo install -Dm644 "$A/etc/sddm.conf.d/99-omarchy-login.conf" /etc/sddm.conf.d/99-omarchy-login.conf

# 3. Wrappers y actualizadores
sudo install -Dm755 "$A/usr/local/bin/update-niri-desktop.sh"       /usr/local/bin/update-niri-desktop.sh
sudo install -Dm755 "$A/usr/local/bin/update-nyxuri-desktop.sh"     /usr/local/bin/update-nyxuri-desktop.sh
sudo install -Dm755 "$A/usr/local/bin/rvim"                         /usr/local/bin/rvim
sudo install -Dm644 "$A/usr/share/applications/top.imsyy.splayer_next.desktop" /usr/share/applications/top.imsyy.splayer_next.desktop

# 4. Servicios systemd y timer
sudo install -Dm644 "$A/etc/systemd/system/niri-update.service"     /etc/systemd/system/niri-update.service
sudo install -Dm644 "$A/etc/systemd/system/niri-update.timer"       /etc/systemd/system/niri-update.timer
sudo systemctl daemon-reload

# 5. Parámetros del kernel Intel i915 (si aplica)
if [ -f "$A/etc/modprobe.d/i915.conf" ]; then
    sudo install -Dm644 "$A/etc/modprobe.d/i915.conf" /etc/modprobe.d/i915.conf
    sudo mkinitcpio -P
fi
```

## 🔍 Comprobar que la Máquina Coincide con el Vault

```bash
VAULT="/home/omarchy/Work/tries/2026-10-23-robert-flo-PJ-NIRI-rf-omarchy-workstation"
A="$VAULT/assets/system"

( cd "$A" && find . -type f | sed 's|^\.||' ) | while read -r f; do
    if sudo cmp -s "$A$f" "$f"; then
        echo "✅ IDENTICO:  $f"
    else
        echo "⚠️  DISTINTO:  $f"
    fi
done
```

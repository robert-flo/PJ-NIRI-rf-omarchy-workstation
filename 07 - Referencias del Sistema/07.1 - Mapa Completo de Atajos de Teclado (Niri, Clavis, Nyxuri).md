En este entorno, la tecla **`Mod`** equivale por defecto a la tecla **Super** (Windows/Command). Si Niri se ejecuta en modo anidado dentro de otra ventana, `Mod` conmuta automáticamente a **Alt**.

Fuentes de configuración:
- `~/.config/niri/config.kdl`
- `~/.config/niri/clavis/binds.kdl`
- `~/.config/noctalia/` (en el entorno Nyxuri)

---

## 🌟 1. Atajos de Clavis Shell (Quickshell IPC)

Todos estos atajos interactúan directamente con el daemon de Clavis vía IPC (`qs -c clavis ...`):

| Atajo | Función | Acción y Descripción |
|---|---|---|
| `Mod + Espacio` | **Spotlight Launcher** | Abre el buscador principal de aplicaciones y archivos. |
| `Mod + Shift + Espacio` | **Búsqueda Web** | Abre Spotlight directo en modo de búsqueda en internet. |
| `Mod + Alt + V` | **Historial del Portapapeles** | Gestor visual de historial de portapapeles (`key clipboard`). |
| `Mod + Alt + W` | **Selector de Wallpapers** | Galería interactiva con cambio dinámico de tema Matugen. |
| `Mod + /` | **Mapa de Atajos** | Muestra en pantalla el mapa visual interactivo de atajos de Clavis. |
| `Mod + A` | **Ajustes Rápidos (Quicksettings)** | Panel lateral derecho: volumen, brillo, Wi-Fi, Bluetooth y perfiles. |
| `Mod + N` | **Dashboard / Notificaciones** | Panel lateral izquierdo: centro de notificaciones, clima y widgets. |
| `Mod + Ctrl + ,` | **Centro de Control** | Panel de personalización y configuración general del entorno. |
| `Mod + Shift + W` | **Keystone Hub** | Panel central interactivo (*Dynamic Island* / control flotante). |
| `Mod + Shift + T` | **Keystone Tools** | Utilidades rápidas (calculadora `libqalculate`, conversión, notas). |
| `Mod + Backspace` | **Menú de Energía** | Opciones para apagar, reiniciar, suspender o cerrar sesión. |
| `Alt + Shift + L` | **Bloqueo de Pantalla** | Bloquea la sesión con la pantalla de bloqueo de Clavis Shell. |

## ❄️ 2. Atajos de Nyxuri Shell (Noctalia / Quickshell)

| Atajo / Comando | Función | Acción |
|---|---|---|
| `Mod + D` / `nyxuri-shell --action launcher` | **Orbit Launcher** | Abre el lanzador de aplicaciones de Noctalia. |
| `nyxuri-shell --action settings` | **Centro de Ajustes** | Panel de control de Nyxuri Shell. |
| `nyxuri-shell --action session` | **Menú de Sesión** | Opciones de apagado, reinicio y cierre de sesión. |
| `~/.config/niri/scripts/toggle-eyecare.sh` | **EyeCare (wlsunset)** | Conmuta filtro de luz nocturna en pantalla. |
| `Mod + Return` | **Terminal Primaria** | Abre la terminal Kitty con tema reactivo. |

## 🪟 3. Navegación y Gestión de Ventanas en Niri

Niri se basa en un paradigma de **columnas desplazables continuas (*scrollable tiling*)**:

### A. Programas y Sistema
| Atajo | Acción |
|---|---|
| `Mod + T` | Abrir terminal predeterminada (`alacritty` / `ghostty`) |
| `Mod + D` | Lanzador alternativo de aplicaciones (`fuzzel` / Orbit) |
| `Mod + Shift + /` | Mostrar ventana de atajos esenciales nativos de Niri |
| `Mod + Escape` | Activar / desactivar captura de atajos por aplicaciones exclusivas |
| `Mod + Shift + E` | Salir de la sesión Niri (solicita confirmación) |
| `Ctrl + Alt + Supr` | Salir de la sesión Niri (atajo alternativo) |
| `Mod + Shift + P` | Apagar pantallas (se reactivan con teclado o ratón) |

---

### B. Gestión de Ventanas y Columnas
| Atajo | Acción |
|---|---|
| `Mod + Q` | Cerrar ventana activa |
| `Mod + O` | Vista general (*Overview*) de espacios de trabajo y columnas |
| `Mod + F` | Maximizar columna (preservando márgenes y bordes) |
| `Mod + M` | Maximizar ventana completa hasta los bordes |
| `Mod + Shift + F` | Modo pantalla completa (*Fullscreen*) |
| `Mod + Ctrl + F` | Expandir columna ocupando todo el espacio libre disponible |
| `Mod + C` | Centrar columna activa en la pantalla |
| `Mod + Ctrl + C` | Centrar todas las columnas visibles simultáneamente |
| `Mod + V` | Alternar entre ventana flotante libre y modo mosaico |
| `Mod + Shift + V` | Conmutar el foco entre ventanas flotantes y mosaico |
| `Mod + W` | Alternar modo pestañas (*tabbed*) dentro de la columna |

---

### C. Desplazamiento del Foco
| Atajo | Acción |
|---|---|
| `Mod + H` o `Mod + Flecha Izq` | Foco a la columna de la izquierda |
| `Mod + L` o `Mod + Flecha Der` | Foco a la columna de la derecha |
| `Mod + K` o `Mod + Flecha Arriba` | Foco a la ventana superior de la columna |
| `Mod + J` o `Mod + Flecha Abajo` | Foco a la ventana inferior de la columna |
| `Mod + Inicio` | Foco a la primera columna del workspace |
| `Mod + Fin` | Foco a la última columna del workspace |

---

### D. Reorganización de Ventanas y Columnas
| Atajo | Acción |
|---|---|
| `Mod + Ctrl + H` o `Mod + Ctrl + Flecha Izq` | Mover columna hacia la izquierda |
| `Mod + Ctrl + L` o `Mod + Ctrl + Flecha Der` | Mover columna hacia la derecha |
| `Mod + Ctrl + K` o `Mod + Ctrl + Flecha Arriba` | Mover ventana hacia arriba dentro de la columna |
| `Mod + Ctrl + J` o `Mod + Ctrl + Flecha Abajo` | Mover ventana hacia abajo dentro de la columna |
| `Mod + Ctrl + Inicio` | Mover columna al inicio del espacio |
| `Mod + Ctrl + Fin` | Mover columna al final del espacio |
| `Mod + [` | Integrar / extraer ventana a la columna izquierda |
| `Mod + ]` | Integrar / extraer ventana a la columna derecha |
| `Mod + ,` | Fusionar ventana contigua derecha en la columna actual |
| `Mod + .` | Expulsar la ventana inferior fuera de la columna |

---

### E. Dimensionamiento
| Atajo | Acción |
|---|---|
| `Mod + R` | Siguiente ancho predefinido (`1/3`, `1/2`, `2/3` de pantalla) |
| `Mod + Shift + R` | Ancho predefinido anterior |
| `Mod + Ctrl + Shift + R` | Siguiente alto predefinido |
| `Mod + Ctrl + R` | Restablecer alto predeterminado de ventana |
| `Mod + -` | Reducir ancho de columna un 10% |
| `Mod + =` | Incrementar ancho de columna un 10% |
| `Mod + Shift + -` | Reducir alto de ventana un 10% |
| `Mod + Shift + =` | Incrementar alto de ventana un 10% |

---

### F. Espacios de Trabajo (Workspaces)
| Atajo | Acción |
|---|---|
| `Mod + 1 ... 9` | Cambiar al espacio de trabajo correspondiente (1 al 9) |
| `Mod + Ctrl + 1 ... 9` | Mover columna activa al espacio de trabajo (1 al 9) |
| `Mod + AvPag` o `Mod + U` | Desplazarse al espacio de trabajo inferior |
| `Mod + RePag` o `Mod + I` | Desplazarse al espacio de trabajo superior |
| `Mod + Ctrl + AvPag` o `Mod + Ctrl + U` | Mover columna al espacio inferior |
| `Mod + Ctrl + RePag` o `Mod + Ctrl + I` | Mover columna al espacio superior |
| `Mod + Shift + AvPag` o `Mod + Shift + U` | Desplazar el espacio de trabajo entero hacia abajo |
| `Mod + Shift + RePag` o `Mod + Shift + I` | Desplazar el espacio de trabajo entero hacia arriba |

---

### G. Navegación con la Rueda del Ratón
| Acción con el Ratón | Efecto |
|---|---|
| `Mod + Rueda Arriba / Abajo` | Cambiar entre espacios de trabajo contiguos |
| `Mod + Ctrl + Rueda Arriba / Abajo` | Mover la columna activa a otro espacio de trabajo |
| `Mod + Rueda Izq / Der` | Desplazar el foco entre columnas |
| `Mod + Ctrl + Rueda Izq / Der` | Mover columna físicamente hacia la izquierda / derecha |

---

### H. Capturas de Pantalla
| Atajo | Acción | Directorio Destino |
|---|---|---|
| `Impr Pant` | Captura interactiva por selección de área | `~/Pictures/Screenshots/` |
| `Ctrl + Impr Pant` | Captura completa de toda la pantalla | `~/Pictures/Screenshots/` |
| `Alt + Impr Pant` | Captura de la ventana activa únicamente | `~/Pictures/Screenshots/` |

---

### I. Teclas Multimedia y Hardware
| Tecla Multimedia | Función |
|---|---|
| `Subir Volumen` | Aumenta el volumen de audio en intervalos del 10% (máx. 100%) |
| `Bajar Volumen` | Reduce el volumen de audio en intervalos del 10% |
| `Silenciar (Mute)` | Conmuta silencio de los altavoces / salida principal |
| `Silenciar Micrófono` | Conmuta silencio de entrada de micrófono |
| `Play / Pausa` | Control de reproducción multimedia (`playerctl`) |
| `Siguiente / Anterior` | Cambiar de pista musical |
| `Brillo + / Brillo -` | Ajustar nivel de brillo de pantalla en intervalos del 10% |

# 🪟 Guía Canónica de Atajos de Teclado: Clavis Desktop

> [!NOTE]
> **Navegación de Capa:**
> * Siguiente: [[07.2 - Repositorios Upstream y Fuentes Externas]]
> * Subir al Hub: [[07.0 - Referencias del Sistema (MOC)|📑 Hub de Capa]]
>
> Esta es la **Referencia Canónica de Producción** para el escritorio **Clavis** sobre Niri (`~/.config/niri/config.kdl` y `/z/rf-dotfiles`). Incluye la suite nativa de Quickshell (Spotlight, Keystone, Paneles laterales) junto con los módulos de productividad integrados (Terminal Scratchpad Kitty 75%, Menú Radial Orbit M3, Traductor interactivo ES↔EN, Ciclo de fondos favoritos y conmutador nocturno).

---

## 🪟 Clavis Shell & Quickshell Suite

| Atajo | Acción | Mecanismo Subyacente |
| :--- | :--- | :--- |
| **`Super + Espacio`** | **Spotlight Universal** (Buscador y lanzador rápido) | `qs -c clavis ipc call spotlight toggle` |
| **`Super + Shift + Espacio`** | **Spotlight: Búsqueda Web** | `qs -c clavis ipc call spotlight web` |
| **`Super + Alt + V`** | **Spotlight: Historial de Portapapeles** | `qs -c clavis ipc call spotlight openMode clipboard` |
| **`Super + Alt + W`** | **Spotlight: Selector Visual de Wallpapers** | `qs -c clavis ipc call spotlight openMode wallpapers` |
| **`Super + /`** | **Mapa de Atajos Gráfico de Clavis** | `qs -c clavis ipc call shortcut-map toggle` |
| **`Super + Retroceso`** | **Menú de Energía** (Apagar, reiniciar, suspender) | `qs -c clavis ipc call power-menu toggle` |
| **`Alt + Shift + L`** | **Bloquear Pantalla** (Clavis Lockscreen) | `qs -c clavis ipc call lock open` |

| **`Super + Shift + T`** | **Keystone: Panel de Herramientas y Monitoreo** | `qs -c clavis ipc call keystone tools` |

## 🪟 0. Atajos de Inicio Rápido y Memoria Muscular

| Atajo | Acción | Observaciones |
| :--- | :--- | :--- |
| **`Super + Enter`** | **Abrir Terminal (Kitty)** | Terminal acelerada GPU por defecto. |
| **`Super + Shift + Enter`** | **Terminal Rápida Scratchpad (Kitty 75%)** | Terminal flotante desplegable tipo Quake (sombra, bordes redondeados y sesión tmux). |
| **`Super + T`** | **Abrir Terminal (Alacritty)** | Terminal secundaria ultraligera. |
| **`Super + D`** | **Lanzador Radial Orbit (M3)** | Menú circular vectorial de apps y utilidades. |
| **`Super + E`** | **Explorador de Archivos (Nautilus)** | Abre la carpeta personal del usuario. |
| **`Super + Q`** | **Cerrar Ventana Enfocada** | Cierre inmediato de la aplicación activa. |
| **`Super + O`** *(o `Super + Tab` / `Super + Alt + Espacio`)* | **Vista General (Overview)** | Vista de pájaro de todos los espacios y ventanas. |
| **`Super + Alt + R`** | **Recargar Configuración de Niri en Caliente** | Aplica cambios de `config.kdl` sin cerrar sesión. |
| **`Super + Alt + N`** | **Modo Cuidado Ocular (Eye Care / Noche)** | Conmuta filtro cálido a 4000 K en Quickshell. |
| **`Super + Alt + E`** | **Traductor Rápido de Selección** | Traduce el texto seleccionado entre Español e Inglés y muestra notificación emergente. |
| **`Super + Ctrl + W`** | **Fondo de Pantalla Aleatorio Instantáneo** | Cambia de wallpaper de forma inmediata vía Quickshell. |
| **`Super + Shift + 1 .. 9`** | **Slots Favoritos de Fondo / Video Animado** | Cambia al archivo `1.*` ... `9.*` de `/z/wallpaper-collection/favorites/` (`.png`, `.webp`, `.mp4`). |

## 🪟 1. Gestión de Ventanas y Modos

| Atajo | Acción | Detalle Técnico |
| :--- | :--- | :--- |
| **`Super + F`** | **Maximizar Columna** | Expande la columna conservando gaps y bordes decorativos. |
| **`Super + Shift + F`** | **Pantalla Completa (Fullscreen)** | Ocupa el 100% de la pantalla sin paneles ni barras. |
| **`Super + M`** | **Maximizar a Bordes Físicos** | Expande la ventana cubriendo los huecos hasta el límite exterior. |
| **`Super + Ctrl + F`** | **Expandir a Espacio Disponible** | Rellena el espacio horizontal restante en la pantalla. |
| **`Super + C`** | **Centrar Columna Activa** | Centra la columna actual en el monitor. |
| **`Super + Ctrl + C`** | **Centrar Todas las Columnas Visibles** | Distribuye las columnas en el monitor. |
| **`Super + V`** | **Alternar Modo Flotante / Mosaico** | Convierte la ventana activa en flotante independiente. |
| **`Super + Shift + V`** | **Alternar Foco entre Capa Flotante y Mosaico** | Mueve el foco del cursor entre la capa flotante y tiled. |
| **`Super + G`** *(o `Super + W`)* | **Alternar Modo Pestañas (Tabbed Group)** | Muestra las ventanas de la columna en pestañas compactas. |

## 🪟 3. Mover y Reorganizar Ventanas

| Atajo | Acción |
| :--- | :--- |
| **`Super + Ctrl + H`** / **`Flecha Izquierda`** | Mover columna a la izquierda |
| **`Super + Ctrl + L`** / **`Flecha Derecha`** | Mover columna a la derecha |

| **`Super + Ctrl + Fin`** | Mover columna al final del workspace |

| **`Super + ]`** | Integrar o expulsar ventana con respecto al vecino derecho |
| **`Super + ,`** *(Coma)* | Meter en la columna la ventana de la derecha (`consume`) |

## 🪟 9. Control Multimedia y Hardware

| Atajo | Acción | Mecanismo |
| :--- | :--- | :--- |
| **`XF86AudioRaiseVolume`** | Subir volumen (+10%, máx 100%) | `wpctl set-volume @DEFAULT_AUDIO_SINK@ 0.1+ -l 1.0` |
| **`XF86AudioLowerVolume`** | Bajar volumen (-10%) | `wpctl set-volume @DEFAULT_AUDIO_SINK@ 0.1-` |
| **`XF86AudioMute`** | Silenciar / restaurar altavoces | `wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle` |
| **`XF86AudioMicMute`** | Silenciar / restaurar micrófono | `wpctl set-mute @DEFAULT_AUDIO_SOURCE@ toggle` |
| **`XF86AudioPlay` / `Pause`** | Reproducir / Pausar medios | `playerctl play-pause` |
| **`XF86AudioStop`** | Detener reproducción | `playerctl stop` |
| **`XF86AudioPrev` / `Next`** | Pista anterior / siguiente | `playerctl previous` / `next` |
| **`XF86MonBrightnessUp / Down`** | Subir / bajar brillo de pantalla (10%) | `brightnessctl --class=backlight set 10%±` |

## 🪟 10. Salida y Recuperación del Sistema

| Atajo | Acción | Comportamiento |
| :--- | :--- | :--- |
| **`Super + Shift + P`** | **Apagar Monitores (DPMS)** | Despiertan de inmediato al mover ratón o pulsar tecla. |
| **`Super + Escape`** | **Inhibidor de Atajos (KVM / Máquinas Virtuales)** | Cede los atajos a ventanas remotas o emuladores. |
| **`Super + Alt + L`** | **Bloquear Pantalla de Respaldo** | Invoca `swaylock` (fallback nativo). |
| **`Super + Shift + E`** | **Salir de la Sesión Niri** | Diálogo de confirmación para cerrar sesión gráfica. |
| **`Ctrl + Alt + Supr`** | **Salida de Emergencia** | Diálogo rápido de confirmación de salida. |

# 👤 Creación de Usuarios y Cuentas de Sistema

> [!NOTE]
> **Navegación:**

Este módulo automatiza la provisión estandarizada de cuentas de usuario en el sistema operativo, garantizando que cada perfil cuente con su directorio personal (`$HOME`), shell `/bin/bash`, pertenencia a grupos administrativos y de hardware, persistencia de demonios (`systemd linger`) y privilegios de `sudo`.

---

## 🎯 Objetivo

Proveer de manera idempotente las cuentas requeridas para la estación de trabajo:
- **`niri`**: Usuario de producción para Niri + Clavis Shell.
- **`sura`**: Usuario desechable de testbench para Clavis.
- **`nyxuri`**: Usuario de producción para Niri + Noctalia Shell.
- **`nyxuri-test`**: Usuario desechable de testbench para Nyxuri.
- **`gracie` / `omarchy`**: Cuentas de administración y entorno Hyprland base.

---

## 🛠️ Procedimiento Automatizado de Provisión

El siguiente script recorre la lista de usuarios y garantiza que existan con los grupos y configuraciones de sistema necesarias:

```bash
sudo bash -c '
set -euo pipefail

TARGET_USERS=("${@:-niri sura nyxuri nyxuri-test}")

for TARGET_USER in "${TARGET_USERS[@]}"; do
    echo "==> Configurando usuario: $TARGET_USER"
    
    # 1. Crear usuario si no existe, o añadir grupos si ya existe
    if ! id "$TARGET_USER" &>/dev/null; then
        useradd -m -s /bin/bash -G wheel,audio,input,video,kvm,storage "$TARGET_USER"
        echo "Usuario $TARGET_USER creado con éxito."
    else
        echo "El usuario $TARGET_USER ya existe. Actualizando membresía de grupos..."
        usermod -aG wheel,audio,input,video,kvm,storage "$TARGET_USER"
    fi

    # 2. Habilitar systemd linger para servicios en segundo plano
    loginctl enable-linger "$TARGET_USER"

    # 3. Configurar permisos de sudoers permanente sin contraseña
    tmp=$(mktemp)
    printf "%s\n" "${TARGET_USER} ALL=(ALL) NOPASSWD: ALL" "Defaults:${TARGET_USER} verifypw = any" > "$tmp"
    visudo -cf "$tmp"
    install -o root -g root -m 0440 "$tmp" "/etc/sudoers.d/04_${TARGET_USER}"
    rm -f "$tmp"
done

echo "✅ Provisión de cuentas completada exitosamente."
' -- "niri" "sura" "nyxuri" "nyxuri-test"
```

## 🔑 Asignación de Contraseña y Desbloqueo de Cuenta (Obligatorio)

> [!CAUTION]
> **Cuentas bloqueadas tras `useradd`:**
> En Linux, cualquier usuario recién creado con `useradd` se inicializa en estado **bloqueado (`L`)** en `/etc/shadow`. El gestor de inicio de sesión (SDDM / greetd) rechazará cualquier intento de autenticación hasta que se le asigne una contraseña explícita.
>
> Ejecuta `passwd` para asignar la clave de cada usuario creado:
>
> ```bash
> for u in niri sura nyxuri nyxuri-test; do
>     echo "==> Establece la contraseña para $u:"
>     sudo passwd "$u"
> done
> ```

## 🔍 Pasos de Verificación y Diagnóstico

1. **Verificar grupos de los usuarios:**
   ```bash
   id niri
   id nyxuri
   # Salida esperada: uid=... groups=...(wheel),...(audio),...(input),...(video),...(kvm)...
   ```

2. **Comprobar privilegios de sudo sin contraseña:**
   ```bash
   sudo -u niri sudo whoami
   sudo -u nyxuri sudo whoami
   # Salida esperada en ambos: root
   ```

3. **Verificar estado de contraseña desbloqueada (P):**
   ```bash
   sudo passwd -S niri
   sudo passwd -S nyxuri
   # Debe mostrar 'niri P ...' (Password set).
   # Si muestra 'niri L ...' (Locked), ejecuta: sudo passwd <usuario>
   ```

4. **Verificar estado de linger:**
   ```bash
   loginctl show-user niri | grep Linger
   # Salida esperada: Linger=yes
   ```

Este módulo documenta e integra la suite de aplicaciones transversales, herramientas de inspección/diff y navegadores web que se utilizan de forma global en todos los escritorios y cuentas del sistema (`gracie`, `niri`, `sura`, `nyxuri`, `nyxuri-test`).

---

## 📋 Inventario de Paquetes Transversales

| Herramienta | Nombre del Paquete | Repositorio / Origen | Categoría | Descripción y Rol |
|---|---|---|---|---|
| **Meld** | `meld` | `extra` (Oficial Arch) | Diff & Merge | Herramienta gráfica de comparación visual de archivos, directorios y resolución de conflictos. |
| **Delta** | `git-delta` | `extra` (Oficial Arch) | CLI & Git | Pager sintáctico para diffs de terminal y git (provee el binario `delta`). |
| **Elio** | `elio-bin` | AUR / Omarchy | Terminal FM | Gestor de archivos para terminal ultrarrápido con soporte de imágenes y previsualizaciones. |
| **Zen Browser** | `zen-browser-bin` | Omarchy / AUR | Navegador Web | Navegador centrado en privacidad, diseño minimalista y pestañas verticales basado en Firefox. |
| **Brave Origin** | `brave-origin-bin` | Omarchy / AUR | Navegador Web | Navegador Brave con arquitectura ligera y protecciones integradas. |
| **Microsoft Edge** | `microsoft-edge-stable-bin` | Omarchy / AUR | Navegador Web | Microsoft Edge oficial para Linux (canal estable). |
| **Google Chrome** | `google-chrome` | Omarchy / AUR | Navegador Web | Google Chrome oficial para Linux (canal estable). |

## 🚀 Procedimiento de Instalación

La instalación se realiza a nivel del sistema operativo para que los ejecutables y archivos `.desktop` estén inmediatamente accesibles desde todos los usuarios y lanzadores gráficos (Orbit Launcher, Clavis Spotlight, Fuzzel o terminales).

### 1. Paquetes Oficiales de Arch Linux (`pacman`)

```bash
sudo pacman -S --needed --noconfirm \
    meld \
    git-delta
```

### 2. Paquetes AUR / Repositorio Omarchy (`paru` o `yay`)

```bash
yay -S --needed --noconfirm \
    elio-bin \
    zen-browser-bin \
    brave-origin-bin \
    microsoft-edge-stable-bin \
    google-chrome
```

## 🛠️ Resumen de Capacidades por Categoría

### 1. Comparación y Diff (`meld` y `git-delta`)
* **`meld`**: Proporciona una interfaz visual de tres vías para resolver fusiones complejas de Git y comparar árboles de directorios completos.
* **`git-delta`** (binario `delta`): Renderiza salidas de `git diff`, `git log -p` o comparaciones directas en consola con resaltado de sintaxis preciso, números de línea e información de rama lado a lado.

### 2. Exploración en Terminal (`elio-bin`)
* **`elio`**: Gestor de archivos interactivo en consola con soporte nativo para previsualización de imágenes Kitty/Sixel, navegación tipo Miller columns y operaciones directas en lote.

### 3. Suite Multilineal de Navegadores Web
El sistema dispone de los cuatro motores/sabores clave para desarrollo web, navegación privada y compatibilidad empresarial:
* **Zen Browser** (`zen-browser`): Navegación diaria con soporte nativo para temas Wayland, pestañas laterales y agrupación de espacios.
* **Brave Origin** (`brave-origin`): Aislamiento y bloqueo estricto de telemetría.
* **Microsoft Edge** (`microsoft-edge-stable`): Compatibilidad de cuentas corporativas y perfiles sincronizados.
* **Google Chrome** (`google-chrome-stable`): Referencia estándar para depuración web y extensiones Chromium.

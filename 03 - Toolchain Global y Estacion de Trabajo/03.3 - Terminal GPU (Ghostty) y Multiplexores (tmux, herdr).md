# 💻 Terminal GPU (Ghostty) y Multiplexores (`tmux`, `herdr`)

> [!NOTE]
> **Navegación:**
> * Anterior: [[03.2 - Toolchain de Desarrollo (C, Rust, Node, Python)|03.2 - Toolchain de Desarrollo (C, Rust, Node, Python)]]
> * Siguiente: [[03.4 - Tipografias y Fuentes del Sistema|03.4 - Tipografías y Fuentes del Sistema]]
> * Volver a: [[03.0 - Toolchain Global y Estacion de Trabajo (MOC)|📑 Índice de Capa]]

Este módulo documenta el entorno de terminal moderno de la estación de trabajo, basado en el emulador acelerado por GPU **Ghostty**, el orquestador de agentes de codificación en paralelo **herdr** y el multiplexor clásico **tmux**.

---

## 📋 Componentes del Entorno de Terminal

| Herramienta | Rol y Características Principales | Paquete / Repositorio |
|---|---|---|
| **Ghostty** | Emulador de terminal de alto rendimiento escrito en Zig, acelerado por GPU vía OpenGL/Vulkan, con soporte nativo para Wayland, true color (24-bit), undercurl estilizado y decoraciones GTK4/Adwaita. | `ghostty` (`extra` / `omarchy`) |
| **herdr** | Gestor de espacios de trabajo diseñado específicamente para ejecutar agentes autónomos de codificación en paralelo, con atajos al estilo tmux (`Ctrl+T`) y organización en cuadrícula o pestañas. | `herdr-bin` (AUR) |
| **tmux** | Multiplexor de terminal robusto para sesiones desatendidas, persistencia de procesos y división de paneles en consola. | `tmux` (`extra`) |

---

## 🚀 Procedimiento de Instalación a Nivel de Sistema

```bash
# 1. Instalar Ghostty y tmux desde repositorios oficiales
sudo pacman -S --needed --noconfirm ghostty tmux

# 2. Instalar herdr desde AUR
yay -S --needed --noconfirm herdr-bin
```

## 🎨 Integración de Temas y Tipografías de Craftzdog

Ghostty está preconfigurado para utilizar la tipografía **`PlemolJP Console NF`** y el tema **`Solarized Dark - Vivid`** portado desde los dotfiles de Craftzdog:

```text
/z/nvims/dotfiles-craftzdog/dot_config/ghostty/
├── config                                # Configuración de Ghostty
└── themes/                               # Temas de color
    ├── Solarized Dark - Vivid            # Tema principal
    └── Solarized Dark - Patched          # Tema alternativo
```

### Configuración de Referencia (`config`)

```ini
theme = "Solarized Dark - Vivid"
desktop-notifications = true
background-opacity = 0.85
background-blur-radius = 20
font-family = "PlemolJP Console NF"
cursor-style = block
cursor-style-blink = true
window-padding-x = 8
window-padding-y = 8
bell-features = no-system
shell-integration-features = ssh-env,ssh-terminfo
```

### Enlace Simbólico para Usuarios

Para que un usuario adopte directamente la configuración y temas compartidos de Ghostty:

```bash
TARGET_USERS=("niri" "sura" "nyxuri" "nyxuri-test")

for u in "${TARGET_USERS[@]}"; do
    if id "$u" &>/dev/null; then
        sudo -u "$u" -H bash -c '
        mkdir -p "$HOME/.config"
        ln -sfn /z/nvims/dotfiles-craftzdog/dot_config/ghostty "$HOME/.config/ghostty"
        '
    fi
done
```

> [!NOTE]
> En la cuenta principal `omarchy`, Ghostty utiliza la integración temática dinámica de Omarchy (`config-file = ?"~/.local/state/omarchy/current/theme/ghostty.conf"`).

## 🤖 Uso de `herdr` con Agentes de Codificación

`herdr` permite levantar múltiples sesiones de terminal con agentes IA lado a lado:
- Prefijo principal: `Ctrl + T`
- Crear panel horizontal: `Ctrl + T` seguido de `"`
- Crear panel vertical: `Ctrl + T` seguido de `%`
- Navegar entre paneles: `Ctrl + T` seguido de las flechas o teclas Vim (`h, j, k, l`).

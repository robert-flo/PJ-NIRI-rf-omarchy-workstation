# 🤖 Ecosistema Google Antigravity y Android Studio Canary (BYOA)

> [!NOTE]
> **Navegación de Capa:**
> * Anterior: [[03.4 - Tipografias y Fuentes del Sistema]]
> * Subir al Hub: [[03.0 - Toolchain Global y Estacion de Trabajo (MOC)|📑 Hub de Capa]]

Este módulo documenta la arquitectura técnica, instalación idempotente y operación multiusuario del stack oficial de **Google**, que combina la suite de desarrollo agéntico con **Google Antigravity**, el entorno de desarrollo móvil **Android Studio Canary (Rabbit con BYOA)**, compiladores de **Java/Kotlin**, sistema de construcción **Gradle**, herramientas de depuración Android y el soporte completo para **Jetpack Compose**.

---

## 🏛️ Componentes del Ecosistema y Justificación Técnica

La estación de trabajo integra las herramientas oficiales de Google organizadas de manera global para que todos los usuarios del sistema (`omarchy`, `omarchy-test`, `niri`, `niri-test`, `nyxuri`, `nyxuri-test`, `nyxuri-legacy`) dispongan de acceso sin duplicar gigabytes en disco ni requerir privilegios de superusuario en el trabajo diario.

### 1. Suite Google Antigravity
1. **Google Antigravity 2.0 (`aur/antigravity`)**:
   - Plataforma de escritorio para orquestación multi-agente paralela de Google (Canvas de agentes, terminales auxiliares, subagentes en background y visualización de artefactos).
   - Origen oficial: Google Cloud Storage (`https://storage.googleapis.com/antigravity-public/antigravity-hub/...`).
   - Binario: `/usr/bin/antigravity`.
2. **Google Antigravity IDE (`aur/antigravity-ide`)**:
   - Entorno interactivo de código basado en VS Code con capacidades nativas de predicción de intención (Tab Autocomplete/Supercomplete), edición guiada (`Ctrl+I`) y panel colaborativo de agente.
   - Origen oficial: Servidores oficiales de Google (`https://dl.google.com/release2/...`).
   - Binario: `/usr/bin/antigravity-ide`.
3. **Google Antigravity CLI (`aur/antigravity-cli`)**:
   - Interfaz de línea de comandos (`agy`) para interacción rápida con agentes directamente desde la terminal, automatización con slash commands (`/goal`, `/plan`, `/schedule`), gestión de subagentes y sidecars.
   - Binario: `/usr/bin/agy`.
4. **Python SDK de Antigravity (`google-antigravity`)**:
   - Librería oficial en Python para orquestar agentes, registrar herramientas MCP personalizadas y automatizar pipelines con la API de Antigravity (`import google.antigravity`).

### 2. IDE Android y Soporte BYOA (Bring Your Own Agent)
5. **Android Studio Rabbit 2/3 Canary (`aur/android-studio-canary`)**:
   - Permite conectar la cuenta de **Google Antigravity** directamente a Android Studio. La funcionalidad **BYOA (Bring Your Own Agent)** se introdujo de manera preliminar exclusivamente en el canal **Canary** a partir de **Android Studio Rabbit 2** (`2026.2.2+`), permitiendo vincular agentes de Google Antigravity, Claude Agent y Codex en `Settings > Tools > AI > Agents`.
   - Binario: `/usr/bin/android-studio-canary`.

### 3. Servicios Cloud, Firebase y Navegador Oficial
6. **Google Cloud CLI (`aur/google-cloud-cli`)**:
   - Proporciona el comando `gcloud` oficial para interactuar con GCP, Vertex AI, Cloud Run y almacenamiento en GCS.
7. **Firebase Tools (`aur/firebase-tools-bin`)**:
   - CLI oficial de Firebase (`firebase`) para emuladores locales de Firestore/Auth/Functions y despliegues móviles.
8. **Google Chrome (`aur/google-chrome`)**:
   - Navegador oficial para flujos de autenticación OAuth de Google Cloud y Android Studio, además de depuración web e inspección con DevTools (`/usr/local/bin/google-chrome`).

### 4. Stack de Compilación: Android, Kotlin, Java y Jetpack Compose
9. **Entorno Java Dual: OpenJDK 21 y OpenJDK 17 (`jdk21-openjdk`, `jdk17-openjdk`)**:
   - Android Studio Rabbit y las versiones actuales de Gradle (8.5+ y 9.x) utilizan Java 21 como estándar del sistema. Proyectos con AGP 8.0 a 8.3 requieren Java 17. Se gestionan con `archlinux-java`.
10. **Compilador Kotlin (`kotlin`)**:
    - Proporciona `kotlinc` y el entorno de ejecución para scripts `.kts` y Kotlin Multiplatform.
11. **Sistema de Construcción Gradle (`gradle`)**:
    - Permite compilar y ejecutar tareas desde la terminal sin depender exclusivamente del wrapper `./gradlew`.
12. **Android Tools y Reglas Udev (`android-tools`, `android-udev`)**:
    - Incluye `adb` y `fastboot`. Las reglas udev en `/usr/lib/udev/rules.d/51-android.rules` evitan errores de permisos al conectar dispositivos físicos reales.
13. **Virtualización por Hardware (KVM - `/dev/kvm`)**:
    - Garantiza que el Android Emulator (AVD) se ejecute con aceleración por hardware a 60/120 fps.

## 🎨 Requerimientos para Jetpack Compose

> [!IMPORTANT]
> **A nivel de Sistema Operativo: NO se requiere ningún paquete binario adicional.**
> 
> 1. **Compilador integrado en Kotlin 2.0+:** El compilador de Compose está fusionado directamente dentro del compilador de Kotlin (`org.jetbrains.kotlin.plugin.compose`).
> 2. **Aceleración Gráfica y Previews:** `@Preview` y **Live Edit** corren en Android Studio usando layoutlib sobre la JVM y la GPU del sistema (Mesa / Vulkan / KVM).

Configuración estándar en `build.gradle.kts` (Módulo `:app`):

```kotlin
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.compose) // Plugin oficial de Compose en Kotlin 2.0+
}

android {
    buildFeatures {
        compose = true
    }
}

dependencies {
    val composeBom = platform("androidx.compose:compose-bom:2026.02.00")
    implementation(composeBom)
    implementation("androidx.compose.ui:ui")
    implementation("androidx.compose.ui:ui-graphics")
    implementation("androidx.compose.ui:ui-tooling-preview")
    implementation("androidx.compose.material3:material3")
    debugImplementation("androidx.compose.ui:ui-tooling")
    debugImplementation("androidx.compose.ui:ui-test-manifest")
}
```

## 👥 Arquitectura Multiusuario y Carpetas Compartidas

Para evitar descargar 30-50 GB de SDK por cada cuenta y habilitar la colaboración sin bloqueos de permisos, se implementa una arquitectura centralizada:

```text
/
├── opt/
│   └── android-sdk/                  # SDK Compartido (Build-tools, platform-tools, platforms)
└── z/
    └── android-projects/             # Directorio colaborativo de proyectos móviles
```

### 1. Modelo de Permisos en Tiempo Real
- **Permisos base:** `2770` (setgid) y propiedad `root:wheel`.
- **ACLs por defecto:** `g:wheel:rwx` heredadas automáticamente para nuevos archivos y carpetas.
- **Monitoreo en tiempo real (`shared_dir`):** Demonios systemd respaldados por `inotifywait` (`android-sdk-perms.service`, `android-projects-perms.service` y `z-perms.service`) reparan de forma inmediata cualquier permiso restrictivo creado por procesos de fondo.

### 2. Variables de Entorno Universales
Para garantizar que **tanto Bash como Fish Shell** carguen las variables sin importar si la sesión es de login, gráfica o no-login:

| Archivo | Ámbito | Propósito |
|---|---|---|
| `/etc/profile.d/android.sh` | Shells de login (POSIX/Bash/Zsh) | Exporta `ANDROID_HOME`, `ANDROID_USER_HOME`, `ANDROID_PROJECTS_DIR` y añade herramientas al `PATH`. |
| `/etc/environment.d/10-android.conf` | Sesiones Wayland / systemd user | Inyecta las variables en los procesos del entorno gráfico (Niri, Hyprland, Android Studio). |
| `/etc/fish/conf.d/android.fish` | Fish Shell (global) | Configura variables nativas de Fish y añade rutas con `fish_add_path` de forma idempotente. |
| `/etc/skel/.bashrc` y `.config/fish/` | Plantilla para nuevas cuentas | Garantiza que cualquier usuario creado con `useradd` herede la configuración de inmediato. |

## 🔗 Vinculación de Antigravity en Android Studio (BYOA)

1. Iniciar Android Studio Canary:
   ```bash
   android-studio-canary &
   ```
2. En la barra lateral o asistente de bienvenida, abrir el panel de **AI / Agent**.
3. Seleccionar **Google Antigravity** de la lista de agentes BYOA (Google Antigravity, Claude Agent, Codex).
4. Si no aparece en la ventana principal, dirigirse a:
   `Settings` $\rightarrow$ `Tools` $\rightarrow$ `AI` $\rightarrow$ `Agents`.
5. Seleccionar **Google Antigravity** e iniciar sesión con la cuenta de Google o registrar la API Key.

## 🔍 Matriz de Comprobación y Diagnóstico

Para auditar el estado del stack completo en cualquier usuario:

```bash
# 1. Herramientas Google y CLI
agy --version
firebase --version
google-chrome --version
python3 -c "import google.antigravity; print('SDK OK')"

# 2. Android Studio e IDEs
which android-studio-canary
which antigravity
which antigravity-ide

# 3. Toolchain de compilación
java -version
kotlinc -version
gradle --version
adb version

# 4. Variables de entorno en la shell actual
echo "ANDROID_HOME: $ANDROID_HOME"
echo "PROJECTS_DIR: $ANDROID_PROJECTS_DIR"

# 5. Permisos en directorios compartidos
test -w /opt/android-sdk && echo "SDK: Escribible" || echo "SDK: ERROR"
test -w /z/android-projects && echo "Proyectos: Escribible" || echo "Proyectos: ERROR"
```

Para garantizar que los entornos de desarrollo, editores (**Neovim dual**), servidores de lenguaje (LSP), linters, formateadores y parsers nativos de sintaxis compilen y operen sin fallos en cualquier cuenta de usuario, el sistema dispone de un toolchain completo instalado a nivel global.

---

## 📋 Inventario del Toolchain de Desarrollo

| Categoría | Paquetes | Propósito y Rol en el Sistema |
|---|---|---|
| **Compiladores C/C++** | `gcc`, `clang`, `make` | Compilación nativa de librerías, módulos C y parsers de sintaxis para `nvim-treesitter`. |
| **Generador de Árboles Sintácticos** | `tree-sitter` | CLI de Tree-sitter para generar e indexar gramáticas de lenguaje en Neovim y herramientas de análisis. |
| **Búsqueda e Indexación** | `ripgrep` (`rg`), `fd` | Motores de búsqueda de alto rendimiento utilizados por los selectores interactivos (Snacks picker, Telescope, FZF). |
| **Control de Versiones y TUI** | `git`, `lazygit` | Control de versiones distribuido y terminal UI para inspección gráfica de commits y ramas. |
| **Toolchain Node.js** | `nodejs`, `npm`, `pnpm` | Ejecución de servidores de lenguaje (TypeScript, Tailwind, Pyright, YAML, Bash LSP) y gestores de dependencias web. |
| **Toolchain Rust** | `rust`, `cargo` | Compilación de utilidades de sistema, soporte para `rust-analyzer` y herramientas CLI modernas. |
| **Entorno Python** | `python` | Soporte para servidores de lenguaje Python (Ruff, Black, Pyright), automatizaciones de sistema y `pynvim`. |
| **Portapapeles e Integración Wayland** | `wl-clipboard` | Provee `wl-copy` y `wl-paste` para comunicación bidireccional entre el portapapeles del sistema y Neovim (`"+y` / `"+p`). |
| **Descarga y Extracción de Binarios** | `unzip`, `tar`, `curl` | Requeridos por gestores como Mason para descargar e instalar binarios precompilados de LSPs sin fallas de descompresión. |

---

## 🚀 Comando de Instalación a Nivel de Sistema

Todos estos componentes forman parte de los repositorios oficiales de Arch Linux (`core` y `extra`) y se instalan de forma desatendida mediante:

```bash
sudo pacman -S --needed --noconfirm \
    gcc clang make tree-sitter \
    ripgrep fd git lazygit \
    nodejs npm pnpm rust cargo python \
    wl-clipboard unzip tar curl
```

## 🔍 Pasos de Verificación

```bash
# 1. Compiladores y parsers
gcc --version | head -n 1
clang --version | head -n 1
tree-sitter --version

# 2. Runtimes de lenguaje
node --version
npm --version
pnpm --version
rustc --version
python --version

# 3. Herramientas de búsqueda y portapapeles Wayland
rg --version | head -n 1
fd --version | head -n 1
which wl-copy wl-paste
```

## 🎯 Resultado y Alcance

La cuenta de administración `gracie` / `omarchy` tiene su `$HOME` versionado con `dotbare` (repositorio bare en `~/.cfg`, `status.showUntrackedFiles no`), segregado de `niri-dotfiles`:

| Archivo / Componente | Estado de Versionado | Rol |
|---|---|---|
| `~/.config/omarchy/shell.json` | Versionado | Configuración de la barra superior de Omarchy. |
| `~/.config/omarchy/extensions/` | Versionado | Extensiones y menú personalizado. |
| `~/.config/hypr/monitors.lua` | Versionado | Configuración de monitores y tasas de refresco para Hyprland. |
| `~/.config/hypr/herald-os.lua` | Versionado | Atajos e integración con Hermes Agent. |
| `~/.bashrc` (bloque `try`) | Versionado | Configuración de la shell interactiva y alias. |

## 🛠️ Uso Diario y Flujo Git

Al igual que en [[06.1 - Gestion de Dotfiles con dotbare|06.1 - Gestión de Dotfiles]]:
- Variables de entorno: `export DOTBARE_DIR="$HOME/.cfg" DOTBARE_TREE="$HOME"`.
- Cada cambio se realiza mediante rama auxiliar $\rightarrow$ PR a `master` $\rightarrow$ rebase merge:

```bash
dotbare checkout -b ajuste/omarchy-bar
dotbare fadd && dotbare commit -m "Ajustar espaciado de widgets en Omarchy"
dotbare push -u origin ajuste/omarchy-bar
gh pr create --repo robert-flo/sura-home --base master --head ajuste/omarchy-bar
```

### Restauración en Otra Máquina (como `gracie`):
```bash
dotbare finit -u git@github.com:robert-flo/sura-home.git
G="git --git-dir=$HOME/.cfg --work-tree=$HOME"
$G config remote.origin.fetch '+refs/heads/*:refs/remotes/origin/*'
$G config status.showUntrackedFiles no
$G fetch origin && $G branch -u origin/master master
hyprctl reload && hyprctl configerrors
```

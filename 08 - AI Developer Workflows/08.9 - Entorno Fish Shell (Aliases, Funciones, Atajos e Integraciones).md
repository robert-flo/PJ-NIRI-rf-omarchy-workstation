# 🐟 08.9 — Entorno Fish Shell (Aliases, Funciones, Atajos e Integraciones)

> [!NOTE]
> **Navegación:**
> * Índice de Capa: [[08.0 - AI Developer Workflows (MOC)|🤖 Capa 08 — AI Developer Workflows]]
> * Fuente de Verdad (Chezmoi): `robert-flo/rf-dotfiles` → `dot_config/fish/`

Esta nota documenta todo lo que ofrece la configuración actual de **Fish Shell** en la estación de trabajo, combinando las integraciones nativas del ecosistema (`clavis-fish-theme`, `zoxide`, `fzf`, `atuin`, `elio`, `yazi`, `try`) con las utilidades, aliases y atajos adoptados de `dotfiles-craftzdog`.

---

## 1. Arquitectura y Carga por Perfil (`config.fish.tmpl` + `conf.d/`)

| Archivo | Alcance | Qué hace |
|---|---|---|
| `config.fish.tmpl` | Por perfil (`clavis`, `nyxuri`, `omarchy`) | En `clavis` inicializa `clavis-fish-theme init fish \| source` (prompt Rust con *transient prompt* y colores sincronizados con Clavis Shell). En `nyxuri` incluye `nyxuri-config.fish`. |
| `conf.d/rf-common.fish` | **Universal (todos los perfiles)** | Variables base (`EDITOR=rvim`, `GOPATH`, `XDG_CONFIG_HOME`, `TRY_PATH=/zt`, `TRY_PROJECTS=$HOME/Work`, `CURSOR_API_KEY`), `PATH`, aliases y `try init`. |
| `conf.d/android.fish` | Universal | Exporta `ANDROID_HOME=/opt/android-sdk`, `ANDROID_USER_HOME`, `ANDROID_PROJECTS_DIR=/z/android-projects` y añade `emulator`, `platform-tools` y `cmdline-tools` al `PATH`. |
| `conf.d/atuin.fish` | Universal | Inicializa `atuin init fish` (historial sincronizado y búsqueda con `Ctrl+R` / `↑`). |
| `conf.d/bat.fish` | Universal | Configura `MANPAGER="sh -c 'col -bx \| bat -l man -p'"` y `MANROFFOPT="-c"` para páginas `man` coloreadas. |
| `conf.d/elio.fish` | Universal | Inicializa `elio shell init fish` (gestor de archivos TUI). |
| `conf.d/fzf.fish` | Universal | Configura `FZF_DEFAULT_OPTS="--reverse --height 40% --border"` e inicializa `fzf --fish`. |
| `conf.d/pay-respects.fish` | Universal | Activa corrección automática de comandos fallidos con el alias `f`. |
| `conf.d/zoxide.fish` | Universal | Inicializa `zoxide init fish` (`z <ruta>` para salto inteligente entre directorios). |

---

## 2. Variables de Entorno y `PATH` (`conf.d/rf-common.fish`)

- **Greeting:** deshabilitado (`set -g fish_greeting ""`).
- **Editor por defecto:** `EDITOR=rvim` (respaldo automático a `nvim` si `rvim` no está disponible).
- **XDG y Go:** `XDG_CONFIG_HOME=$HOME/.config`, `GOPATH=$HOME/go`.
- **Rutas en `PATH`:** `$HOME/.local/bin`, `$GOPATH/bin`, `$HOME/.cargo/bin`, `node_modules/.bin`, más las rutas de Android SDK.
- **Tries y proyectos:** `TRY_PATH=/zt`, `TRY_PROJECTS=$HOME/Work`.
- **Cursor CLI:** si existe `~/.config/cursor/api-key`, lo exporta automáticamente en `CURSOR_API_KEY`.

## 3. Aliases Activos

| Alias | Comando real | Propósito |
|---|---|---|
| `ll` | `eza -l -g --icons=auto` | Listado largo con iconos y grupo (fallback a `ls -l` si no hay `eza`). |
| `lla` | `ll -a` | Listado largo incluyendo archivos ocultos. |
| `la` | `ls -A` | Listado corto incluyendo archivos ocultos. |
| `vim` | `rvim` | Abre Neovim con la configuración unificada `rvim` (fallback a `nvim`). |
| `agy` | `$HOME/.local/bin/agy` | Lanza Antigravity CLI con detección automática de tema claro/oscuro y `--dangerously-skip-permissions`. |
| `claude-yolo` | `claude --dangerously-skip-permissions` | Lanza Claude Code sin confirmaciones interactivas. |
| `pn` | `pnpm` | Atajo para `pnpm`. |
| `cz` | `chezmoi` | Atajo para `chezmoi`. |
| `f` | `pay-respects` | Corrige el último comando que falló. |

> [!NOTE]
> No se importan aliases de `git` ni de `gh` desde configuraciones externas para respetar los aliases propios de tu flujo.

## 4. Funciones Personalizadas (`functions/`)

| Función | Archivo | Qué hace |
|---|---|---|
| **`cpwd`** | `functions/cpwd.fish` | Copia al portapapeles (`wl-copy`) la ruta actual (`$PWD`) reemplazando `$HOME` por `~` y sin salto de línea final. |
| **`envsource <archivo>`** | `functions/envsource.fish` | Carga variables de entorno desde un `.env` en la sesión actual (`set -gx`), ignorando comentarios `#`, líneas vacías, prefijo `export ` y comillas envolventes. |
| **`fzf_change_directory`** | `functions/fzf_change_directory.fish` | Lista con `fd` + `fzf` tus repositorios Git en `/z-home-repos/HR-CLAVIS`, `/z/repos`, `/z-drive/tries`, `~/Work`, `~/.config` y subcarpetas actuales (excluyendo `.pj`), y hace `cd` directo al seleccionado. |
| **`yazi` / `fm`** | `functions/yazi.fish`, `functions/fm.fish` | Wrappers de `yazi` con `--cwd-file`: al salir de Yazi cambia el directorio de la terminal a la carpeta donde te quedaste (*cd-on-exit*). |

## 5. Atajos de Teclado (`functions/fish_user_key_bindings.fish` + integraciones)

| Atajo | Acción | Fuente |
|---|---|---|
| **`Ctrl+F`** | Abre `fzf_change_directory` para saltar a cualquier repositorio o carpeta de trabajo. | `fish_user_key_bindings.fish` |
| **`Ctrl+D`** | Borra el carácter bajo el cursor (`delete-char`) en lugar de enviar `EOF` y cerrar accidentalmente la pestaña/pane de Herdr o Ghostty. | `fish_user_key_bindings.fish` |
| **`Ctrl+R`** | Búsqueda interactiva en el historial sincronizado de Atuin. | `conf.d/atuin.fish` |
| **`Ctrl+T` / `Alt+C`** | Inserción de archivos / salto de directorio con `fzf --fish`. | `conf.d/fzf.fish` |

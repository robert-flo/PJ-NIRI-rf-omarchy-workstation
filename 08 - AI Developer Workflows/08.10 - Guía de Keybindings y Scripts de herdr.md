# Guía de Keybindings y Scripts de `herdr` (con Ghostty)

> [!NOTE]
> **Navegación:**
> * Índice de Capa: [[08.0 - AI Developer Workflows (MOC)|🤖 Capa 08 — AI Developer Workflows]]

> * Fuentes de Verdad: `rf-dotfiles/dot_config/herdr/config.toml` y `rf-dotfiles/dot_config/ghostty/config`.

> Ghostty actúa como emulador puro (copy/paste, fuente, paleta, reload) y cede todos los splits, tabs y workspaces a `herdr`.

---

## 1. Tecla maestra (`prefix`)

Tu `prefix` es **`Ctrl+Space`** (soltás `Ctrl+Space` y después apretás la segunda tecla).

---

## 2. Navegación directa (sin `prefix`)

| Atajo | Qué hace | Respaldo con `prefix` |
| --- | --- | --- |
| `Ctrl+Shift+h/j/k/l` | Mover foco izquierda / abajo / arriba / derecha | `Prefix+h/j/k/l` |
| `Alt+1` .. `Alt+9` | Ir directo a la tab 1..9 | `Prefix+1..9` |
| `Ctrl+Shift+Left` / `Right` | Mover tab a la izquierda / derecha | — |
| `Ctrl+Shift+[` / `]` *(o `Ctrl+{` / `}`)* | Workspace anterior / siguiente | — |
| `Ctrl+Shift+Up` / `Down` | Subir / bajar workspace en la lista (`herdr-move-workspace`) | — |

---

## 3. Paneles (`Ctrl+Space` + tecla)

| Atajo | Qué hace |
| --- | --- |
| `Ctrl+Space` luego `v` | Split vertical (al lado) |
| `Ctrl+Space` luego `s` | Split horizontal (abajo) |
| `Ctrl+Space` luego `x` | Cerrar el panel actual |
| `Ctrl+Space` luego `Shift+E` | Cerrar **todos los demás paneles** de la tab |
| `Ctrl+Space` luego `z` | Maximizar / restaurar el panel actual (`zoom`) |
| `Ctrl+Space` luego `;` | Volver al último panel activo |
| `Ctrl+Space` luego `Shift+H/J/K/L` | Redimensionar el panel actual |

---

## 4. Tabs, Workspaces y Sesión (`Ctrl+Space` + tecla)

| Atajo | Qué hace |
| --- | --- |
| `Ctrl+Space` luego `c` | Nueva tab |
| `Ctrl+Space` luego `n` / `p` | Tab siguiente / anterior |
| `Ctrl+Space` luego `Shift+X` | Cerrar la tab actual |
| `Ctrl+Space` luego `r` | Renombrar la tab actual |
| `Ctrl+Space` luego `[` | Copy mode (scrollear y copiar con teclado) |
| `Ctrl+Space` luego `f` | Goto (buscar y saltar rápido) |
| `Ctrl+Space` luego `b` | Mostrar / ocultar la barra lateral izquierda |
| `Ctrl+Space` luego `Shift+N` | Abrir el destino de una notificación |
| `Ctrl+Space` luego `Shift+R` | Recargar `config.toml` |
| `Ctrl+Space` luego `d` | Detach de `herdr` |

---

## 5. Herramientas, scripts y plugins (`Ctrl+Space` + tecla)

| Atajo | Qué hace | Script / Plugin |
| --- | --- | --- |
| `Ctrl+Space` luego `Up` / `Down` | `herdr-plus`: proyectos / quick actions | `cloudmanic.herdr-plus` |
| `Ctrl+Space` luego `g` | Abre `lazygit` en el directorio del panel | `lazygit` |
| `Ctrl+Space` luego `y` / `Shift+Y` | Abre `elio` en panel / en tab nueva | `robert-flo.elio` |
| `Ctrl+Space` luego `o` | Abre el directorio actual en gestor gráfico (`xdg-open`) | `xdg-open` |
| `Ctrl+Space` luego `i` | Arma layout IDE (franja inferior con 3 consolas) | `~/.local/bin/ide` |

---

## 6. Scripts propios / de craftdog en `~/.local/bin/`

- **`herdr-move-workspace up|down`**: reordena el workspace actual en la barra lateral hablando directo al socket Unix `~/.config/herdr/herdr.sock` (`workspace.move`). Atado a `Ctrl+Shift+Up` / `Ctrl+Shift+Down`.
- **`ide`**: toma el panel izquierdo de la tab actual, crea una franja inferior del 20% (`--ratio 0.8`) y la divide en 3 consolas lado a lado. Atado a `Ctrl+Space` luego `i` (o corriendo `ide` desde terminal).
- **`elio`**: explorador de archivos en terminal integrado vía plugin `robert-flo.elio`. Atado a `Ctrl+Space` luego `y` / `Shift+Y`.

---

## 7. Comandos útiles de `herdr` en la terminal

```bash
# Workspaces
herdr workspace list
herdr workspace create --cwd /ruta/al/repo --label mi-repo
herdr workspace focus <workspace_id>
herdr workspace close <workspace_id>

# Paneles
herdr pane split --direction right --ratio 0.5
herdr pane split --direction down --ratio 0.7
herdr pane zoom --toggle
herdr pane close <pane_id>

# Agentes y config
herdr agent list
herdr agent read <nombre-agente> --lines 40
herdr server reload-config
```
